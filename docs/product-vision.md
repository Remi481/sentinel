# Sentinel Product Vision

## Vision

Sentinel is a cloud-native infrastructure monitoring and security platform that provides real-time visibility into Windows and Linux systems through secure monitoring agents, centralized data collection, and intelligent analytics.

The goal of Sentinel is to simplify infrastructure management by giving administrators a single place to monitor system health, performance, and security across multiple devices.

---

## Mission

To build a lightweight, secure, and scalable monitoring platform that combines observability and cybersecurity into one modern solution.

---

## Target Users

- Developers
- System Administrators
- Small Businesses
- IT Teams
- Students learning cloud technologies

---

## Core Principles

### Security First

Every device communicates securely.

---

### Cross Platform

Runs on Windows and Linux.

---

### Cloud Native

Designed for deployment on AWS.

---

### Real-Time

Data should be available within seconds.

---

### Scalable

Support one device today.

Support thousands tomorrow.
